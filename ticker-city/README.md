# Ticker City

An interactive stock watch list drawn as a 3D city.

- **Districts are sectors.** A district's size grows with the number of stocks in it.
- **Towers are stocks.** Taller means better grades; the roof colour is the verdict
  (Strong Buy, Buy, Watchlist, Hold, Pass).
- **Tap a district** to open a fighting-game style roster. **Tap a stock** for its S–E radar chart
  (Moat, Financial health, Growth, Profitability, Management, Valuation) and its strengths and weaknesses.
- **Full Dossier & Outlook** shows the thesis, risks, outlook, current news and sources.
- **Live chart on TradingView** opens the stock's live price in a new tab.
- **My Watch** holds your own tickers. **Buzz Boulevard** holds the stocks with the most chatter on X and Reddit.

Live page: https://claude.ai/artifact/YA6SqcKgFAT7paumaF8mVg (private to the owner until shared)

## How it fits together

| Piece | Where |
|---|---|
| Page (HTML + Three.js r128) | `ticker-city.html`, published as a claude.ai Artifact |
| Stock data | The artifact's database: `stocks/<TICKER>`, `mywatch/<TICKER>`, `meta/status` |
| First data load (Nov 18, 2026) | `data/seed/*.json`, generated by `scripts/seed_stocks.py` |
| Daily updates | Scheduled task, see `DAILY_TASK.md` |

The page holds no stock data itself. It reads the database live, so daily updates show up without
republishing the page.

### Stock document fields

`ticker, name, district (tech|comm|consumer|health|fin|industrial|buzz), price, changePct, priceDate,
verdict, stats{moat,health,growth,profit,mgmt,value} (S–E), tagline, strengths[], weaknesses[], thesis[],
moat, outlook, news, risks[], changeMind[], entryNote, sources[{title,url}], analyzedAt, method, buzz?`

## Making changes

Edit `ticker-city.html`, then ask Claude to republish it to the same artifact URL
(publishing from a new conversation needs the URL above).

Why prices aren't streaming live: the artifact runs in a sandbox that blocks requests and embeds from
other sites (TradingView included), so prices come from the daily update. A copy hosted on GitHub Pages could
embed TradingView's free widgets for live quotes, but it wouldn't have the artifact database.

Grades come from a quick screen, not a full analysis. This is research, not financial advice.
